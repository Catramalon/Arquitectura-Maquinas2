El Motor Computacional

Organización del CPU

Estudio detallado del procesador: el ciclo de instrucción (Fetch/Execute), los elementos estructurales (Datapath y Control) y el análisis de las arquitecturas de manejo de operandos.

2.2 El Ciclo de Instrucción

Fase FETCH (Búsqueda)

  • Cargar instrucción: Extraer de la memoria apuntada por el PC hacia el IR.
  • Incrementar secuenciador: Un sumador (+1) ajusta el PC para apuntar a la próxima instrucción.
  • Interpretar: El Decoder evalúa el IR para determinar la operación.

Fase EXECUTE (Ejecución)

  • Cargar operandos: Desde instrucción (inmediato), memoria o registros de propósito general (R0...Rn).
  • Ejecutar operación: En la ALU (Z ← X op Y).
  • Guardar y Verificar: Actualizar el PSW/FLAGS (Z, N, S, C, V) y atender si hay señales INT (Interrupciones).

2.3 & 2.4 Elementos para estructurar el Procesador

El CPU se construye con electrónica digital (Flip-flops, MUX, Decoders) agrupados en dos secciones clave: Datapath y Control.

PC & IR

El PC (Program Counter) usa un Adder1 para secuenciar. El IR (Instruction Register) resguarda la instrucción actual para el Decoder.

MAR & MDR

Interactúan con la Memoria Externa mediante el Bus de Direcciones (MAR) y el Bus de Datos (MDR).

ALU & GPR

El Órgano de cálculo (ALU) trabaja junto a los Registros de Propósito General (R0..Rn) para realizar aritmética lógica.

PSW (Flags)

Almacena códigos y banderas de condición que actualizan el estado tras los cálculos (Z, N/S, C, V).

2.5 Arquitecturas del Procesador

1 Dirección (Acumulador)

Posee un solo registro central (Acc) en el CPU. Instrucciones definen un único operando.

LOAD X ; Acc ← M(X) ADD X ; Acc ← Acc + M(X) STORE X ; M(X) ← Acc

0 Direcciones (Pila)

No almacena operandos en CPU, sino en memoria (empuje abajo). Usa SP, TOS y NOS.

PUSH X ; TOS ← M(X) POP Z ; M(Z) ← TOS ADD ; TOS' ← NOS + TOS

2 y 3 Direcciones (Registros)

Múltiples registros internos para operandos. La de 2D tiene lectura destructiva (fuente/destino).

; 2 Direcciones: ADD Rf, Rd ; Rd ← Rf + Rd ; 3 Direcciones: ADD Rd, Rf1, Rf2 ; Rd ← Rf1+Rf2
