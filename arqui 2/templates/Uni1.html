1.1 Introducción

Arquitectura y Organización

El proceso constructivo de una computadora consta de la Planificación y Diseño (Arquitectura) y culmina en la Implementación física (Organización).

Arquitectura vs Organización

Arquitectura

Comprende los atributos visibles al programador. Es la fase de diseño lógico donde se define cómo funcionará el sistema conceptualmente.

Organización

Trata sobre la implementación física. Define los componentes de hardware reales y su interconexión para cumplir las especificaciones arquitectónicas.

1.4 Organización de la Computadora (Vistas)

El análisis de una computadora se puede realizar mediante dos enfoques complementarios:

Enfoque Funcional

Orientado a las funciones requeridas para lograr el objetivo. Sus 4 operaciones básicas son:

  • Procesamiento de datos.
  • Almacenamiento de datos.
  • Traslado de datos.
  • Operaciones de control.

Enfoque Estructural

Orientado a definir las partes físicas y cómo se conectan. Sus componentes principales son:

  • Procesador o CPU.
  • Memoria Principal.
  • Entrada - Salida (E/S).

1.3 Máquina Secuencial de Programa Almacenado

Programa Almacenado

Define instrucciones simples para programar cualquier tarea. La clave revolucionaria es la posibilidad de cargar estos programas en la misma memoria que se cargan los datos.

Máquina Secuencial

Para realizar la tarea, basta lograr que la máquina realice el programa ejecutando instrucción tras instrucción desde la memoria, gracias a un secuenciador (control).

Las 5 Unidades Funcionales

(Actualización del concepto original de Charles Babbage)

  1. Órgano de cálculo: Ejecuta las instrucciones.
  2. Memoria: Almacena datos e instrucciones.
  3. Control: El secuenciador maestro.
  4. Unidad de Entrada: Obtiene datos del mundo exterior.
  5. Unidad de Salida: Entrega los resultados.
